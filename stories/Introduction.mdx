# Welcome to Stagehand Storybook

This is the Storybook for the Stagehand project - an AI web browsing framework focused on simplicity and extensibility.

## About Stagehand

Stagehand is a powerful tool for browser automation and web scraping powered by AI. It provides:

- **Simple API**: Easy-to-use methods for common browser tasks
- **AI-Powered Actions**: Intelligent element detection and interaction
- **Extensibility**: Built to be extended and customized
